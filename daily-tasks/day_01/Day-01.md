
# Day 1: Dataset Inspection

## Objective
To load and inspect the Hotel Booking Demand dataset.

## Tasks Completed
- Loaded the CSV dataset using Pandas.
- Checked dataset dimensions and column names.
- Displayed the first five records.

- Counted duplicate rows.

- Checked booking cancellation counts.
